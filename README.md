# E-Commerce Landing Page

A modern e-commerce landing page showcasing products with an attractive design and call-to-action elements.

## 📋 Overview

A professional landing page built with HTML and CSS designed to showcase products, attract customers, and drive conversions.

## 🛍️ Features

- **Responsive Design** – Mobile, tablet, and desktop optimized
- **Product Showcase** – Featured products with images and descriptions
- **Call-to-Action** – Prominent purchase and inquiry buttons
- **Navigation** – Easy-to-use menu structure
- **Contact Section** – Get in touch functionality
- **Modern Aesthetics** – Clean and professional design

## 🛠️ Technologies Used

- **HTML5** – Semantic markup
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactive elements
- **No Framework** – Pure vanilla code

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/Scarface96/e-commerce-landing-page.git
cd e-commerce-landing-page

# Open in browser
open index.html  # macOS
# or
start index.html  # Windows
```

Or run a local server:
```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server
```

Then visit `http://localhost:8000`

## 📱 Sections

- **Header** – Navigation and logo
- **Hero** – Attention-grabbing banner
- **Products** – Product cards with details

## 📖 How to Use

1. **Browse** – View featured products
2. **Read** – Learn about features and benefits
3. **Contact** – Fill out contact form or use provided contact info
4. **Purchase** – Click order buttons for more details
